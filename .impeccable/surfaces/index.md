## Direction contract

THESIS: 두 문명이 지형째 맞물린 한 장의 세계. 카드 격자·명단 패널 대신, 한쪽은 먹과 종이, 한쪽은 석재와 금속으로 만든 두 벌의 부품이 한 화면에서 맞닿는다. 카테고리 기본(검정 바탕 + 발광 테두리 + 카드 3장 반복)을 거부한다.

OWN-WORLD: 동방 부품 = 회백 종이 바탕에 먹이 번진 명패, 붓끝으로 끝나는 사선 테두리, 주사색 낙관 하나. 서방 부품 = 석회색 석판과 무광 은·낮은 채도 금 테, 아치형 액자, 문장 방패. 회색지대 = 두 재질이 톱니처럼 맞물린 띠, 종이 등과 기름 램프 두 불빛. 구간 명도: 흑청 밤(장면) → 회백 낮(인물) → 먹빛 전장(전선) → 석재(세력·체계) → 흑청(시작). 서체: 이름 Noto Serif KR(동 500 넓은 자간 / 서 700 좁은 자간), 본문 Pretendard, 타이틀 붓글씨는 자산에 한정.

STORY: 첫 화면에서 지형이 맞물린 대표 장면을 보고 → 한쪽을 고르면 그 문명의 건축이 다가오고 세력·인물이 드러난다 → 인물 구간에서 큰 그림을 고르면 제자리에서 펼쳐진다 → 전선·세력·체계에서 연결을 더듬는다 → 시작 모드로 간다.

FIRST VIEWPORT: 전면 대표 배경(서쪽 성채·석조 ← 회색지대 → 동쪽 기와·산세) 위, 왼쪽 아래 한글 타이틀(붓글씨 자산 + 낙관)과 「서방 / 동방」 두 선택 버튼(각 재질 부품). 오른쪽 위 공통 메뉴. 대표 인물은 분리 자산이 오기 전까지 배경 위 독립 면으로.

FORM: 기획서 §2가 핀한 방향(동서 재질 대비). 롤 없이 핀 방향으로 진행(작가님 지정). seed: pinned-by-brief.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

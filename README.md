# 검과 마나의 경계 — 소개 사이트

무협 vs 중세 판타지 전면전 작품 「검과 마나의 경계」의 소개 사이트. 정적 HTML/CSS/JS, GitHub Pages 배포.
기획: 작업 폴더의 `웹사이트 기획/검과 마나의 경계 — 소개 사이트 제작 기획.md` (2026-10-25 사용자 피드백 반영본).

## 구성 (`index.html` 한 장, 세로 흐름)
1. 대표 장면 — 서방 아치 면 / 동방 사선 면 / 회색지대 띠. 진영을 고르면 그 면이 확장되고 세력·인물이 나타난다
2. 인물 — 이미지 자체를 고른다. 서방·동방 두 군의 시작 높이가 다르고 중립은 아래에서 잇는다. 고르면 제자리에서 중앙 감상 영역으로 펼쳐진다(`#A`, `#A/16`)
3. 전선 — SVG 개념도. 표식을 고르면 확대되고 대치 세력·관련 인물이 나타난다(`#f-north`)
4. 세력·힘의 체계 — 세력을 고르면 소속 인물·관련 전선 강조. 동방 경지 7단과 서방 기사·서클을 「대응 감각」대로 같은 행에 정렬
5. 시작 — 무림 측·서방 측·자유모드. 프롤로그·작품 링크는 미연결 상태로 표시

지리: 동대륙 서쪽 끝과 서대륙 동쪽 끝이 맞붙었으므로 지도·장면·인물 모두 **서방 왼쪽, 동방 오른쪽**.

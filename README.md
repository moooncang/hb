# 검과 마나의 경계 — 소개 사이트

무협 vs 중세 판타지 전면전 작품 「검과 마나의 경계」의 소개 사이트. 정적 HTML/CSS/JS, GitHub Pages 배포(https://moooncang.github.io/hb/).
기획: 작업 폴더의 `웹사이트 기획/검과 마나의 경계 — 소개 사이트 제작 기획.md`. 디자인 규칙: `DESIGN.md`. 제품 기준: `PRODUCT.md`.

## 페이지
- `index.html` 입장 + 장면 — 표지: 달 위의 먹글씨 제목, 달을 감싸고 도는 월마의 기운 고리 세 겹과 숨 쉬는 번짐, 설정집 첫 문장, 공통 그림 실제 로딩 진행(「등을 켜는 중」), 전선 넷 로그. 누르면 아르델의 오러 검격이 화면을 대각선으로 긋고, 섬광과 함께 두 조각이 화면 밖으로 밀려나며 아래의 장면이 드러난다(같은 세션에서는 한 번만). 장면: 아르델(왼쪽)·위지란(오른쪽) 원화가 톱니 이음새로 맞물린 한 화면, 이음새 위의 세로 제목, 면이나 토글로 진영을 고르면 그쪽이 넓어지고 세력·인물 정보가 나타난다 → 전황(네 전선) → 17인 얼굴 액자 → 세계 세 단 → 세력 문장 띠 + 사다리 → 시작 모드
- `home.html` — `index.html`로 넘긴다(예전 링크용)
- `characters-west.html` 서방 인물 = **동방의 기록** — 동방이 서방 인물에 관해 모아 둔 두루마리. 호칭은 동방 별호(「금관」)로 적고, 등급 옆에 설정집 대응 감각(화경 등)을 붙인다. 기록 한 장(카드: 번호 도장, 액자에 든 원화, 컷 띠 셋, 세력 문장 투문, 관찰 한 줄)을 세로로 쌓고, 누르면 긴 기록이 펼쳐진다(등장 카드 첨부, 무대 틀·상태별 컷, 기록 표, 관계, 관찰·내력·외모·호칭·무공(`assets/records.js`, 설정집 문장 그대로), 소속 세력·전선, 원고 슬롯, `#G`, `#G/16`). 회색지대(레나타)는 양쪽 다
- `characters-east.html` 동방 인물 = **서방의 기록** — 서방이 모아 둔 양피지 서류. 호칭은 서방 이명(「천흑의 마녀」). 구성은 거울
- `characters.html` — 예전 링크용. 인물 부호에 따라 두 페이지로 넘긴다
- `fronts.html` 전선 — 개념도 위 표식(`#north`)과 오른쪽 타이포 목록, 대치 세력·인물, 붉은 천·전쟁 일감·포로 세 단
- `order.html` 세력·체계 — 문장 12종 타이포 목록(`#murim`), 서로 부르는 말, 경지 선·기둥 도해, 상성, 관계 단계
- `start.html` 시작 — 모드 카드 3장(`#east`), 공통 규칙, 프롤로그 틀, 미연결 링크
- 머리·메뉴 마크업은 여섯 파일에 같은 블록을 복사해 둔다(빌드 도구 없음). 단축키 1~6 페이지 이동, Esc 메뉴·기록 닫기. 글자 규칙·조형 규칙은 `DESIGN.md`
- 페이지 전환: 미리 만들어 둔 와이프(먹 번짐은 scale, 오러 날은 그라데이션 면의 이동 — 변형만 움직인다)가 덮고, 들어오는 쪽은 먹으로 덮인 채 시작해(머리의 인라인 스크립트가 sessionStorage `hb-wipe`를 읽어 `html[data-wipe]`) 글꼴이 준비되는 대로 걷힌다 — 두 페이지가 한 호흡으로 이어진다. 세부는 `DESIGN.md` 「움직임」
- v4 주문서 `design/ui-asset-order-v4.md`(두루마리·양피지 서류 카드 가로·세로 + 긴 기록 위·띠·아래, 10장) → 납품 `design/incoming-v4/`(2026-10-26, 접합행 채널 차이 0 검수) → `tools/build-skin4.ps1`(종이 띠 두 장만 JPEG) → `assets/skin4/`(16MB). `main.js`의 `ART.doc`이 켜져 있어 기록 카드와 긴 기록이 그림이다(끄면 종이·석재 질감 판)

지리: 동대륙 서쪽 끝과 서대륙 동쪽 끝이 맞붙었으므로 지도·장면·인물 모두 **서방 왼쪽, 동방 오른쪽**.

## 사운드

- `assets/audio.js`가 6개 페이지에 공통으로 연결된다. 첫 입장 클릭·키보드 입력부터 음악과 효과음이 재생되며, 첫 동작 전에는 MP3를 요청하지 않는다. 오른쪽 위 스피커 버튼에서 전체 켜기·끄기, 곡 선택, 배경음악·효과음 볼륨을 따로 조절한다. 기본값은 음악 28%, 효과음 60%이며 사용자가 명시한 음소거는 유지한다.
- 준비된 `../사운드트랙/`의 MP3 원본 3곡을 그대로 복사했다: `red-cloth.mp3`(RED CLOTH · 메인 테마), `tianmen.mp3`(천문관 · 동방 전선), `valtrock.mp3`(발트로크 · 서방 성채). 자동 선택은 장면의 진영, 인물, 세력, 시작 모드에 맞추고 수동 선택은 유지한다.
- 설정은 localStorage, 곡별 재생 위치와 첫 동작 여부는 sessionStorage에 저장한다. 페이지를 이동하면 같은 곡을 마지막 위치에서 재개한다. 탭을 벗어나면 일시 정지하고, 재생 권한이 막히면 다음 사용자 동작을 기다린다. 저장소를 차단한 환경에서도 현재 페이지 조작은 동작한다.
- 음악은 MediaElement + Web Audio gain으로 페이드 인/볼륨을 적용한다. 일반 UI 효과음은 필터 노이즈·짧은 배음으로 합성한다. 입장 검격은 Mixkit의 실제 스윙·검 충돌·파열 소스 4종을 8개 층으로 편집한 `assets/audio/entry-slash.wav`(2.5초, 약 431KiB)다. 0.35초 칼날 통과 → 0.65초 충격 → 1.13초 화면 분리·파편에 맞추고, 검격 동안 음악을 낮춘다. 사용 조건과 출처는 `assets/audio/SOURCES.txt`, 재제작은 `tools/build-entry-audio.cjs`.
- 입장 준비 중 검격 WAV를 미리 받아 해독하고, 첫 클릭에서 오디오 잠금이 풀리는 시간만큼 파일 위치를 보정한다. 파일 실패 시에도 5초 뒤에는 입장 준비를 진행한다. `index.html?intro=1`로 같은 세션에서 입장 연출을 다시 확인할 수 있다.
- 버튼 클릭·미세 호버, 진영 선택, 메뉴 열기·닫기, 인물 기록·컷·카테고리·필살기, 확대·닫기, 지도 표식·전선 목록, 세력·경지, 시작 모드, 일반 링크·단축키의 페이지 전환에 동작별 소리를 연결했다. 전용음이 있으면 기본 클릭음을 겹치지 않는다. 호버는 마우스를 실제로 움직일 때만 재생하며, 모션 감소 설정에서는 입장·전환음을 짧게 처리한다. 음소거·탭 비활성화 시 예약된 효과음도 중단한다.
- 확인: `node tools/serve.js 8788` 실행 후 Playwright와 Edge가 있는 환경에서 `node tools/test-audio.cjs` 및 `node tools/test-effects.cjs`. 3곡 재생, 설정·위치 복구, 페이지 이동 후 재개, 자동 재생 차단, 저장소 차단, 오류 재시도, 모바일 폭, 실제 FX 출력·검격 시각표·클리핑·동작별 중복 재생·효과음 끄기를 검증한다. 로컬 서버도 MP3 byte range를 지원한다.

## 그림 자산
- v3 주문서 `design/ui-asset-order-v3.md`(장면 세로·가로·먹 제목, 균열 띠, 검격 8층) → 납품 `design/incoming-v3/`(13장, 2026-10-26) → `tools/build-skin3.ps1`(크기 검수, 큰 층만 균일 축소) → `assets/skin3/`(7.5MB). `assets/main.js`의 `ART` 표시가 켜져 있어 제목·균열·검격 층이 그림이다(끄면 글꼴 제목·빛선·v2 검격으로 돌아간다)
- v2 납품 원본 `design/incoming-v2/`(주문서 `design/ui-asset-order-v2.md`, 자리별 고정 크기 + 입장 연출, GPT 이미지 생성) → `tools/build-skin2.ps1`(불투명 판은 JPEG, 커버 안개·검격·섬광·달만 축소) → `assets/skin2/`
- v1 납품 원본 `design/incoming/`(주문서 `design/ui-asset-order.md`) → `tools/build-skin.ps1` → `tools/diet.ps1` → `tools/diet-panels.ps1` → `assets/skin/`. v2로 대체된 v1 부품(버튼·칩·이름패·목록 띠·판·키 비주얼)은 지웠다
- 부품은 늘리지 않는다: 그림 px의 정확히 1/2 크기 상자에 `background-size: 100% 100%`, 글자는 주문서의 글자 영역에만. 그림 부품은 버튼·칩·토글·대표 이름표·얼굴 액자·무대 틀·입장 연출에만 쓰고, 판·명패·목록 띠 종류는 쓰지 않는다(편집과 글자가 뼈대, `DESIGN.md`). 상태 그림은 `::before`에 겹쳐 두고 투명도로 바꾼다
- 타이틀과 이름은 `main.js`의 `fit()`이 판 폭에 맞춰 글자 크기를 정한다
- 도해 좌표(경지 선 마디, 기둥 x, 지도 표식 %)는 `assets/main.js`에 있다. 그림이 바뀌면 `tools/measure.ps1`로 다시 잰다

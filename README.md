# 검과 마나의 경계 — 소개 사이트

무협 vs 중세 판타지 전면전 작품 「검과 마나의 경계」의 소개 사이트. 정적 HTML/CSS/JS, GitHub Pages 배포(https://moooncang.github.io/hb/).
기획: 작업 폴더의 `웹사이트 기획/검과 마나의 경계 — 소개 사이트 제작 기획.md`. 디자인 규칙: `DESIGN.md`. 제품 기준: `PRODUCT.md`.

## 페이지
- `index.html` 입장 + 장면 — 표지: 달 위의 먹글씨 제목, 달을 감싸고 도는 월마의 기운 고리 세 겹과 숨 쉬는 번짐, 설정집 첫 문장, 공통 그림 실제 로딩 진행(「등을 켜는 중」), 전선 넷 로그. 누르면 아르델의 오러 검격이 화면을 대각선으로 긋고, 섬광과 함께 두 조각이 화면 밖으로 밀려나며 아래의 장면이 드러난다(같은 세션에서는 한 번만). 장면: 아르델(왼쪽)·위지란(오른쪽) 원화가 톱니 이음새로 맞물린 한 화면, 이음새 위의 세로 제목, 면이나 토글로 진영을 고르면 그쪽이 넓어지고 세력·인물 정보가 나타난다 → 전황(네 전선) → 17인 얼굴 액자 → 세계 세 단 → 세력 문장 띠 + 사다리 → 시작 모드
- `home.html` — `index.html`로 넘긴다(예전 링크용)
- `characters.html` 인물 — 탐색 범위 칩, 얼굴 바로 가기 띠, 서방·동방 두 군(시작 높이 차) + 중립. 이름·별호는 그림 밖 여백에 획과 함께. 고르면 제자리에서 펼쳐지는 감상(무대 틀, 상태 분류·컷, 큰 이름과 설정 표, 원고 슬롯, 관계, 소속 세력·전선 문장, 등장 카드, `#A`, `#A/16`)
- `fronts.html` 전선 — 개념도 위 표식(`#north`)과 오른쪽 타이포 목록, 대치 세력·인물, 붉은 천·전쟁 일감·포로 세 단
- `order.html` 세력·체계 — 문장 12종 타이포 목록(`#murim`), 서로 부르는 말, 경지 선·기둥 도해, 상성, 관계 단계
- `start.html` 시작 — 모드 카드 3장(`#east`), 공통 규칙, 프롤로그 틀, 미연결 링크
- 머리·메뉴 마크업은 다섯 파일에 같은 블록을 복사해 둔다(빌드 도구 없음). 단축키 1~5 페이지 이동, Esc 메뉴·감상 닫기. 글자 규칙·조형 규칙은 `DESIGN.md`

지리: 동대륙 서쪽 끝과 서대륙 동쪽 끝이 맞붙었으므로 지도·장면·인물 모두 **서방 왼쪽, 동방 오른쪽**.

## 그림 자산
- v3 주문서 `design/ui-asset-order-v3.md`(장면 세로·가로·먹 제목, 균열 띠, 검격 8층) → 납품 `design/incoming-v3/`(13장, 2026-10-26) → `tools/build-skin3.ps1`(크기 검수, 큰 층만 균일 축소) → `assets/skin3/`(7.5MB). `assets/main.js`의 `ART` 표시가 켜져 있어 제목·균열·검격 층이 그림이다(끄면 글꼴 제목·빛선·v2 검격으로 돌아간다)
- v2 납품 원본 `design/incoming-v2/`(주문서 `design/ui-asset-order-v2.md`, 자리별 고정 크기 + 입장 연출, GPT 이미지 생성) → `tools/build-skin2.ps1`(불투명 판은 JPEG, 커버 안개·검격·섬광·달만 축소) → `assets/skin2/`
- v1 납품 원본 `design/incoming/`(주문서 `design/ui-asset-order.md`) → `tools/build-skin.ps1` → `tools/diet.ps1` → `tools/diet-panels.ps1` → `assets/skin/`. v2로 대체된 v1 부품(버튼·칩·이름패·목록 띠·판·키 비주얼)은 지웠다
- 부품은 늘리지 않는다: 그림 px의 정확히 1/2 크기 상자에 `background-size: 100% 100%`, 글자는 주문서의 글자 영역에만. 그림 부품은 버튼·칩·토글·대표 이름표·얼굴 액자·무대 틀·입장 연출에만 쓰고, 판·명패·목록 띠 종류는 쓰지 않는다(편집과 글자가 뼈대, `DESIGN.md`). 상태 그림은 `::before`에 겹쳐 두고 투명도로 바꾼다
- 타이틀과 이름은 `main.js`의 `fit()`이 판 폭에 맞춰 글자 크기를 정한다
- 도해 좌표(경지 선 마디, 기둥 x, 지도 표식 %)는 `assets/main.js`에 있다. 그림이 바뀌면 `tools/measure.ps1`로 다시 잰다
